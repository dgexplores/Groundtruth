# Groundtruth

The 'Groundtruth' project ensures the reliability of AI retrieval systems through rigorous evaluation against a managed golden dataset.

## Run
```bash
python3 -m pytest tests/ -q                          # test suite (48 tests)
python3 -m evals.runner                              # retrieval benchmark -> evals/reports/latest.json
python3 -m evals.runner --mode qa                    # exact-match QA scoring (stub model)
python3 -m evals.regression_gate evals/baseline_report.json evals/reports/latest.json --metric recall_at_10
```

The gate fails (exit 1) when the metric drops more than the 0.05 tolerance below baseline; a report missing the metric exits 2 instead of silently scoring it as zero.

## Benchmark Table

Measured, not asserted: `evals/baseline_report.json` is generated by `python3 -m evals.runner` and committed as the gate baseline.

| Metric | Measured | Gate floor | Corpus |
| :--- | :--- | :--- | :--- |
| **recall@5** | 1.0000 | — | 50 docs / 50 queries |
| **recall@10** | 1.0000 | 0.9500 | 50 docs / 50 queries |
| **exact_match** (QA mode) | 0.1000 | — | 50 QA pairs, stub model |

Setup: TF-IDF retriever (scikit-learn), cosine ranking, one relevant document per query, `Recall@K` computed by `src.evaluator.evaluate_retrieval`.

## Tradeoff
The gate threshold was set to a 0.05 tolerance to balance strict quality control with the reality of stochastic retrieval. We accept minor variance in semantic matches while blocking breaking changes in critical business logic queries.

## Honest Failure Notes

- **recall 1.00 measures the harness, not retrieval strength.** The bundled starter corpus was authored so each answer appears in a natural sentence overlapping its query — a lexical retriever should pass it. The number verifies that indexing, ranking, scoring and gating work end to end; it says nothing about semantic difficulty. Drop a real corpus into `evals/corpus.json` (documents + queries with `relevant_ids`) to get a meaningful score.
- **TF-IDF cannot match paraphrases.** Queries that share no vocabulary with the relevant document score zero regardless of correctness; no synonyms or embeddings are involved.
- **One relevant doc per query** makes recall@K binary per query (hit rate). Multi-label corpora give partial credit.
- **Bug the benchmark caught:** scikit-learn's default `token_pattern` drops single-character tokens, so the query `2 + 2` produced an empty vector and scored 0. Fixed via `TfidfRetriever.TOKEN_PATTERN` with a regression test in `tests/test_retriever.py`.
- **QA mode's 0.10 is a stub, not a model.** `simulate_llm` is a fixed lookup table; every report from that mode is labelled `stub:not-a-real-model`.
